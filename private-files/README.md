# Private spreadsheets

Drop files in this folder. WordPress lists them on the Members hub only for **administrators** and the **Finance** role. Direct web URLs do not work: the folder is mounted outside the site root.

**Use:** `.xlsx` (Excel — opens as a table in the browser, with a download), `.csv`, `.pdf` (opens in the browser), `.ods`, or a `.numbers` package (downloads as a zip). Apple Numbers is not Excel; export to Excel or PDF from Numbers to view it here.

Do not put these files in Media, `uploads/`, or `images/`. Those are either public or not gated.

Assign access: **Users →** the person → **Role: Finance**.
